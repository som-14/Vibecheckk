# VibeCheck Data Architecture & DP-900 Alignment

This document outlines the data storage architecture for VibeCheck, mapping workload requirements to core Microsoft DP-900 data categories.

## 1. Data Classification Matrix

| Data Classification | Storage Technology | Target Workload / Entities | Implementation Status (Local) | Target Status (Azure) |
|---|---|---|---|---|
| **Structured Data** | PostgreSQL 15 (Relational SQL) | Users, TargetPersonas, Videos, ViralityPredictions, AgentCritiques, AuditLogs, Performance Views | Implemented | Planned (Azure Database for PostgreSQL Flexible Server) |
| **Semi-Structured Data** | JSON / Document Store (Cosmos DB) | Timestamped Whisper audio transcripts, raw multi-agent critique JSON payloads, frame-level object tags | Implemented (as JSON structures in worker pipeline) | Planned (Azure Cosmos DB NoSQL API) |
| **Unstructured Data** | Blob Storage (Object Store) | Raw uploaded MP4 short videos, extracted 16kHz WAV audio tracks, generated video thumbnail PNGs | Implemented (Local storage mock `/backend/storage`) | Planned (Azure Blob Storage with Hot tier) |

## 2. Planned Power BI Dashboards

All analytical dashboards below are categorized as **Planned** for deployment using Power BI DirectQuery connected to the PostgreSQL analytical views and Cosmos DB data feeds.

### Dashboard 1: Hook Pacing Correlation Dashboard (Planned)
- **Objective:** Evaluates the relationship between visual cuts within the first 3 seconds of a video and resulting virality scores.
- **Key Metrics:** Average cut count in first 3 seconds, correlation coefficient between hook cuts and retention, percentage of videos scoring $\ge 70$ (VIRAL classification) based on pacing velocity.
- **Visuals:** Scatter plot with regression line (Cut Count vs. Virality Score), histogram of cut frequency across viral vs. low-performing videos.

### Dashboard 2: Niche Virality Heatmap (Planned)
- **Objective:** Tracks content performance across target audience personas and content categories over selectable time horizons (7d, 30d, 90d).
- **Key Metrics:** Mean virality score per persona, total video volume analyzed, viral success rate percentage (`viral_success_rate_pct` from `v_creator_performance_summary`).
- **Visuals:** Matrix heatmap (Target Persona vs. Topic Category), stacked bar chart showing classification distribution (VIRAL, AVERAGE, LOW) by demographic.

### Dashboard 3: Retention Drop-Off Analysis Dashboard (Planned)
- **Objective:** Pinpoints specific timestamp markers where viewers disengage, correlated with agent critique feedback.
- **Key Metrics:** Drop-off rate percentage across video duration, critique severity distribution (`CRITICAL`, `MEDIUM`, `INFO`), agent role contribution breakdown.
- **Visuals:** Line chart displaying viewer retention curve from second 0 to second 60, overlaid with agent critique marker pins indicating detected flaws.
